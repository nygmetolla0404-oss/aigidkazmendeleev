# aigidkazmendeleev

**AI-ГИД: Қазақстанның химия әлеміне саяхат** — педагогикалық идеялар фестиваліне арналған интерактивті сайт.

- 3D Қазақстан картасы: кен орындары, элемент кубтары, табиғи орындар
- Әр кен орны — VR-әлем: карьер, шахта, ұңғымалық шаймалау, теңіз кен орны, зауыт, тұзды көл
- Дрон және электромобиль экскурсиялары (картада да, VR-әлемдерде де)
- Виртуалды зертхана, эффектті тәжірибелер мен қауіпсіздік кеңестері
- 3D тапсырмалар (функционалдық сауаттылық, «Адал азамат»), квест, трейлерлер
- Қазақша аудиогид (kk-KZ-AigulNeural)

Автор: Абдихалилова Мохинур Абдимуталовна, химия пәні мұғалімі, Айша бибі атындағы ЖББМ КММ.

Ашу: `index.html` файлын браузерде ашыңыз (3D кітапхана, фото мен қаріптер үшін интернет қажет).
